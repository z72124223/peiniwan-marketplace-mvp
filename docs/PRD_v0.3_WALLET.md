# 陪玩師錢包 PRD v0.3

## 1. 這一版要解決什麼

陪玩師需要看得懂每一筆訂單收益目前在哪個階段，平台也需要一份可追查、不可任意改寫的帳務紀錄。可靠度點數則用來管理接單資格，不能與實際款項混為一談。

本版只建立錢包基礎，不代表真實付款、提領或撥款已啟用。

## 2. 兩種完全分開的帳戶

### 2.1 收益錢包

收益錢包以新台幣最小單位的整數記帳，畫面顯示四種狀態：

- 待入帳：訂單已成立，但仍在服務完成、退款或爭議等待期。
- 可提領：已通過等待期，未被凍結且可進入外部撥款流程。
- 爭議凍結：因退款或爭議暫時不能撥款。
- 已撥款：外部金流服務商已確認撥款的歷史紀錄。

收益錢包不是平台儲值餘額，不允許玩家儲值、互轉或以餘額付款。

### 2.2 可靠度點數

可靠度點數只反映陪玩師的接單可靠程度，例如未在規定時間內接受已選定的邀請時扣點。點數必須符合以下限制：

- 不可購買。
- 不可轉讓。
- 不可提領。
- 不可折抵服務費。
- 不可兌換現金或任何有價物。
- 不可直接扣除已賺取的收益。

本版只建立點數帳本；實際初始值、扣點值、恢復方式與停權門檻仍待營運規則確認。

## 3. 帳務原則

1. 所有金額以最小貨幣單位整數保存，不使用浮點數。
2. 每個收益事件使用 double-entry ledger（雙式帳本），同一貨幣的借方與貸方必須相等。
3. 已過帳紀錄不可更新或刪除；錯誤只能新增一筆沖正交易。
4. 每個外部或訂單事件都有唯一 idempotency key（冪等鍵），重送不會重複入帳。
5. 點數同樣採追加式紀錄；沖正會新增相反分數，不修改原紀錄。
6. 當點數變動會使餘額小於 0 時拒絕過帳。

## 4. 示範頁需求

`/wallet` 在本版是唯讀示範頁，必須：

- 顯示「Demo 帳務預覽・沒有真實款項」。
- 分別顯示待入帳、可提領、爭議凍結與已撥款。
- 將可靠度點數放在獨立區塊，顯示不可兌現限制。
- 顯示幾筆示範收益與點數事件。
- 不提供可按的提領、儲值或轉帳操作。

## 5. 正式開放前的必要條件

- 陪玩師登入、身分綁定與權限檢查。
- 外部金流及撥款服務商完成整合。
- 身分與收款資料審核流程完成。
- 退款、爭議、釋放與撥款規則經人工確認。
- 帳本對帳、異常警示與人工稽核工具完成。

在上述條件完成以前，任何真實款項 mutation（寫入操作）都維持關閉。
