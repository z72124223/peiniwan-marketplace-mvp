# 金錢點數錢包 PRD v0.4

## 1. 核心定義

平台點數是 monetary credits（貨幣型點數），不是評分或遊戲經驗值。

- 玩家使用台幣購買點數。
- 玩家使用點數支付陪玩服務。
- 點數未來可購買虛擬禮物與其他平台商品。
- 陪玩師取得的收益點數可依正式規則兌換現金。
- 暫不開放玩家間轉點、點數買賣或點數交易市場。
- 本 Demo 使用「1 點 = NT$1」的示範匯率；正式匯率尚未確認。

本版先完成正確資料契約、帳務規則與唯讀畫面，不代表真實儲值、扣款或兌現已啟用。

## 2. 服務付款流程

### 2.1 買點

玩家付款成功後，系統依當時匯率把點數加入玩家的可用餘額。交易同時保存：

- 實收台幣最小單位。
- 發放點數。
- 每點台幣價值快照。
- 外部金流參照與唯一冪等鍵。

### 2.2 玩家選擇陪玩師

玩家點選陪玩師時，所需點數先從「可用」移至「保留」，不是立即完成消費。

- 陪玩師在 1 分鐘內接受：點數維持保留，等待服務完成。
- 陪玩師拒絕或逾時：玩家的保留點數全數回到可用餘額。
- 同一邀請重送不能重複保留或重複返還。

### 2.3 陪玩師逾時扣款

陪玩師打卡代表已準備接單。被玩家選中後若 1 分鐘內未接受：

1. 陪玩師自動下線。
2. 玩家保留點數全數返還。
3. 系統從陪玩師錢包扣除可兌現點數。
4. 扣款建立獨立的 `missed_offer_penalty` 事件，保存邀請、點數、台幣價值、規則版本與原因。
5. 申訴成立時新增沖正事件，不修改或刪除原扣款。

本版不決定正式扣款點數。餘額不足、申訴期限與自動停權規則仍待人工確認，系統不得把錢包扣成負數。

### 2.4 服務完成

服務完成且沒有退款或爭議後：

- 玩家保留點數正式扣除。
- 平台費依訂單快照入帳。
- 陪玩師淨收益先進「待入帳」。
- 等待期結束後移至「可兌現」。
- 爭議期間可移至「凍結」，但不能無紀錄消失。

### 2.5 現金兌換

可兌現點數進入外部撥款流程後，必須保存申請、審核、匯率、費用與撥款結果。錯誤只能沖正，不得直接改寫歷史餘額。

## 3. 虛擬禮物

本版只預留 `gift_purchase` 與 `gift_earning` 帳務事件，不提供商城或按鈕。正式開放前仍需確認禮物價格、平台分潤、收禮者所得、退款與爭議規則。

## 4. 帳務原則

1. 點數與台幣價值都是整數，不使用浮點數。
2. 每筆點數事件保存 `points_delta`、`balance_after_points`、`twd_value_minor` 與 `twd_minor_per_point_snapshot`。
3. 台幣資金與點數負債使用 double-entry ledger（雙式帳本），借貸必須平衡。
4. 點數帳本採追加式紀錄；錯誤以相反分錄沖正。
5. 每個外部、訂單、邀請或禮物事件都有唯一 idempotency key（冪等鍵）。
6. 可用、保留、待入帳、可兌現與凍結餘額均不得小於 0。
7. 玩家間轉點、點數買賣與點數交易市場維持關閉。

## 5. `/wallet` 示範頁

頁面必須正確顯示：

- 台幣買點數。
- 玩家可用與已保留點數。
- 陪玩師待入帳、可兌現與凍結點數。
- 1 分鐘未接單會直接扣除陪玩師錢包點數。
- 點數可以兌換現金。
- 暫不開放玩家間轉點與點數交易市場。
- 目前仍是 Demo，沒有接收或撥付真實款項。

頁面不得再出現「點數不是錢」「點數不可購買」或「點數不可兌現」。

## 6. 正式啟用 Gate

這個模型同時具有預先儲值、支付服務對價、條件成就後轉給收款方與現金兌換特徵。金管會《電子支付機構管理條例》第 3 條將預先存放款項供多用途支付定義為「收受儲值款項」，並將條件成就後移轉實質交易款項定義為「代理收付實質交易款項」：

- https://law.fsc.gov.tw/LawContent.aspx?id=GL001488&media=print

此外，若實際營運關係被認定為勞動契約，平台控制工作時間、不得拒絕指派與懲處都可能成為從屬性判斷因素；《勞動基準法》第 26 條亦禁止雇主預扣工資作為違約金或賠償費用：

- https://laws.mol.gov.tw/FLAW/FLAWDOC01.aspx?flno=3&id=FL092317
- https://laws.mol.gov.tw/FLAW/PrintFLAWDOC01.aspx?flno=26&id=FL014930

因此正式啟用真實儲值、逾時扣款與兌現以前，至少需要：

- 合規電子支付／代收付合作商。
- 玩家與陪玩師登入、KYC、權限與交易限額。
- 儲值款保管、對帳、退款、爭議與異常警示。
- 陪玩師契約關係及逾時扣款規則的台灣法律覆核。
- 可查詢、申訴、人工沖正與通知流程。

上述 Gate 不阻擋資料模型與 Demo，但會阻擋真實錢包寫入。
