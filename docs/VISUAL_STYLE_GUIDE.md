# 狼群視覺基準 v1

## 基準資產

- 主要 reference image（參考圖）：`public/voice-room-wolf-campfire.png`
- 首頁唯一例外：`public/hero-husky-night.webp`（愛將主圖），不得以營火圖替換或覆蓋。
- 陪玩師照片屬內容資料，保留真人影像；視覺基準只規範其容器、遮罩、邊框與色調。

## 核心感受

深夜森林、共同冒險、營火旁的安全感。可愛但不幼稚；神秘但不陰森；精緻但不華麗。介面應像一支小隊在夜色中集合，而不是一般電商或霓虹電競網站。

## 色彩系統

| Token | 用途 | 色彩 |
| --- | --- | --- |
| `--paper` | 全站深夜底色 | `#03070e` |
| `--paper-deep` | 更深的森林陰影 | `#060c14` |
| `--card` | 主要深藍面板 | `#0b1420` |
| `--card-strong` | 高層級面板 | `#101d2b` |
| `--line` | 月光藍灰邊線 | `#203246` |
| `--ink` | 主文字 | `#f4f7fb` |
| `--ink-soft` | 次要文字 | `#9db0c1` |
| `--accent` | 營火焦點與主要操作 | `#f2ad5d` |
| `--accent-dark` | 營火按壓／深色狀態 | `#c47a35` |
| `--moon` | 月光資訊與次要互動 | `#8ebddb` |
| `--green` | 安全、在線與完成狀態 | `#73d3a0` |
| `--danger` | 警示與中斷狀態 | `#ff9a8f` |

營火橘只用在操作、眉題、焦點與少量引導，不可大面積覆蓋頁面。主要畫面永遠由深藍夜色主導。

## 材質與層級

1. 頁面底層：深藍黑漸層，可加入極淡的森林／營火氣氛，不影響閱讀。
2. 主要面板：半透明深藍、月光細邊線、低亮度內層漸層。
3. 互動面板：比主要面板亮一階；hover（游標停留）時只提高邊線與背景亮度。
4. 語意狀態：成功使用松林綠、警示使用低飽和紅；仍保留深夜材質，不使用純白底。
5. 陰影：只表達層級，不做厚重浮空卡片。使用深色大範圍柔影，避免暖棕陰影。

## 排版

- 大標題與情緒型標題：`Noto Serif TC`／宋體類，營造故事與冒險感。
- 導覽、表單、資料與操作：`Noto Sans TC`／黑體類，維持清楚與效率。
- 英文眉題可使用大寫與寬字距，但只作小比例標示。
- 避免把每段文字放進獨立膠囊；膠囊只用於狀態、標籤與短資料。

## 元件規則

- Header／Footer：深夜半透明材質、細月光邊線；品牌焦點使用營火橘。
- 主要按鈕：營火橘底、深色文字；次要按鈕：深藍透明底、月光邊線。
- 表單：深藍輸入面、清楚焦點環；選中狀態使用低透明營火光。
- 卡片／面板：共用表面、邊線與陰影；允許不同資訊密度，不要求每個區塊都有圓角外框。
- 圖片：保留內容真實性，統一冷色調、邊線與遮罩；不得用生成狼圖取代真人資料。
- 警示：深紅棕透明面＋紅色文字；成功：深松綠透明面＋綠色文字。

## 頁面背景規則

- 首頁首屏：只使用愛將主圖 `hero-husky-night.webp`。
- 其他主要路由：可在頁面背景使用低對比、低透明的 `voice-room-wolf-campfire.png` 氛圍層。
- 語音房：可完整使用營火圖，因它是基準圖的原生使用情境。
- 不在同一個可見區域重複多張完整營火圖。

## 禁止事項

- 純白／米白大卡片或暖灰紙張感。
- 霓虹紫、亮青色電競光污染或大面積高飽和漸層。
- 每個資訊都包成圓角膠囊或浮空卡片。
- 用不同風格的生成圖混合，造成角色或世界觀不一致。
- 為了視覺統一而弱化錯誤、安全、Demo 或未連線等必要揭露。

## 新頁面驗收

- 是否以深藍夜色為主、營火橘只作焦點？
- 是否使用既有 token，而非新增相近硬編碼色？
- 是否沿用共用按鈕、表單、表面與狀態規則？
- 是否在桌面與約 390px 手機寬度保持可讀且無水平溢位？
- 是否保留 Demo、未連線、未付款或安全邊界等真實狀態？
